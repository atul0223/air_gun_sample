# MEERUT AIRGUN - High-End Ballistics & Armory Showcase

An Awwwards-tier showcasing web experience built for **Meerut Airgun** ([@meerutairgun](https://www.instagram.com/meerutairgun)), located in Ganganagar, Meerut (Near IIMT University).

## Features
- **Cinematic Tactical Dark Aesthetic**: Double-Bezel (Doppelrand) hardware framing, OLED charcoal background with subtle ballistic grid and phosphor amber/tritium highlights.
- **Interactive Rotary Magazine Simulator**: 
  - 10-shot circular magazine drum with spring indexing
  - Click to load/seat individual .177 match pellets
  - Cycle the side-lever biathlon bolt action to chamber rounds
  - Fire test with reactive paper target hits and recoil sound
- **Procedural Web Audio Synthesizer**:
  - Zero external audio files required
  - Real-time synthesized metallic bolt rack, pellet seat click, trigger snap, and shrouded pneumatic air discharge
- **Live HTML5 Ballistics Flight Dynamics Lab**:
  - Simulates trajectory arc across 10m to 100m
  - Compares Wadcutter (8.2gr), Domed Diabolo (10.3gr), and Precision Slugs (13.5gr)
  - Interactive velocity (650 - 1100 FPS), distance, and crosswind sliders
  - Real-time readouts for Muzzle Energy (Joules), Flight Duration (ms), and Drop (cm / inches)
- **Interactive Weapon Anatomy & Cutaway Explorer**:
  - Hotspot navigation of 300-Bar carbon fiber cylinder, match regulator, 2-stage trigger, sound moderator, and optics
- **Product Armory with 1-Click WhatsApp Inquiries**:
  - Directly opens pre-configured WhatsApp chat targeting Meerut Airgun (+91 8439543244 / +91 9286453001)
- **Legal Compliance Guide**:
  - Indian Arms Rules, 2016 .177 caliber sports exemption documentation

## How to Run

### Option 1: Direct Browser
Simply double-click `index.html` or open it with your browser.

### Option 2: Live Local Server
```bash
# In the meerut-airgun-showcase folder:
npx serve .
# Or with Python:
python -m http.server 3000
```
